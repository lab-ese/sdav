# New Statistical Exercises in R

## Questions

1. **Student Data Frame & ggplot2**: Create data frame with student names, marks, grades. Subset students scoring above 75. Install ggplot2 and create scatter plot.

2. **Airline Delays**: Read dataset, display structure and summary. Compute mean, median, mode.

3. **E-commerce Statistics**: Read dataset, display structure and summary. Calculate SD, variance, coefficient of variation.

4. **Merchandise Sales Visualization**: Plot histogram, boxplot, and stem-and-leaf display.

5. **One-sample t-test**: Perform on Merchandise Sales dataset to check if sample mean differs from population mean.

6. **One-way ANOVA**: Compare means across three groups in Airline Delays dataset.

7. **Poisson Distribution**: Find probability of events in fixed interval using Merchandise Sales.

8. **Chi-square Distribution**: Calculate probabilities for Airline Delays dataset.

9. **F-test**: Compare variances of Merchandise Sales and E-commerce datasets.

10. **Chi-square Test**: Test independence between two categorical variables in E-commerce.

11. **Function & If-Else**: Create function to compute average and classify number as positive/negative/zero.
